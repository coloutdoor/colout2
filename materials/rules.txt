    If info is missing, write "MISSING" in caps.

    You only output raw material lists after the summary.

    The estimate will have a deck size like 20.0 x 40.0, 10 ft high

    The Projection (out from house) will always be the first number, and the deck width will be the second number.
    Supply and install 800.0 sq ft of TimberTech Prime deck. Deck size approximately 20.0 x 40.0 ft, 10.0 ft high.
    This is
            20’ (Projection) out from house
            40’ (Width) and 10’ off the ground.

    All Framing materials should be PT.
    Hardware / fasteners should be galvanized or zinc coated.
    Most hardware is Simpson


    All lengths of beams and joists should be in multiples of 2.  Min 8’ max 20’.

    Footings and Framing

    For the footings we need concrete.
    Standard footing size:  16” x 16” x 12” deep
    Decks at 6’ or Higher should be 20” x 20” x 12” deep
    Decks at 12’ or higher should be 24” x 24” x 12” deep

    The width of the deck will determine the number of footings. Minimum of 2 footings. Add an additional footing for each 10’ in deck width.  At 11’ wide we need 3 footings.

    Also double the footings if the projection from the house is > 12’.  This is double the footings and double the headers.

    We also need 2x4 Doug fir for the footing frames.  1 2x4 @ 8’ per footing

    Example:
         3 footings @ 16x16x12
            3 - 2x4 8’ DF
            .86 - yards concrete or xx bags 80# concrete

    Posts. (pressure treated)
    Under 6’ - 4x4 PT with ABU44Z and PC44Z
    6’ - 10’  - 4x6PT with ABU 46Z and PC46Z
    10’ - 20’ - 6x6 PT with ABU 66Z
     The length of these posts should be greater than the deck height.

    Header (Pressure treated)
        Width - Match 4x or 6x posts
        Thickness…  10”   4x10 or 6x10
        Total length > width of deck.

    Joists
         Wood decks at 24” o.c.  Composite at 16” o.c.
         Always order enough joists for 12” oc.  For a 20’ wide deck, order 20 joists.
         You can also only order half the quantity and double the size.  For a 6’ projection you can order 12’ joists.  Be sure to put this in the final notes.
          Projection - Out from house:
          < 6’ - 2x4
          6’ - 8’ - 2x6
          8’ - 10’ - 2x8
          10’ - 12’ - 2x10
          >12’  - Error
       ** The length of the joists should be greater than the projection out.  And should be in multiple of 2.

    Ledger:
          Match joist size.  This should match the width of the deck.

    Rim Joist:
           Only add a rim joist to match the ledger.
           Do not add “side” rim joists

    Stair Stingers:  @ 16” o.c.  Add 1 extra.  The stair stringer length should be 2x the height.

    Specify hardware Hardware:  Be sure to specify the “z” for Zinc on all Simpson hardware.
         – ABU - Post base (ABU 44z, ABU46z, ABU 66z)

    Decking / Trim

    This should be the total square feet of the deck. If the exact color / brand of the board is not specified in the bid, please add a note in the output.  Composite deck boards come in 12’ 16’ and 20’ boards.  Composite deck boards come in 2 options:
    1.  Grooved -> these require deck clips (Trex or Timbertech to match brand)
    2.  S4S -> these go around the perimeter of the deck, and are also used on stairs treads

    You will have to calculate the number of stair treads based on the height if this is not explicitly stated.
       - Each tread will need 8’ - a 16’ S4S board can do 2 treads

    Fascia length should be specified. Fascia boards only come in 12’ lengths, and has 2 sizes
       7” - Used for stair treads 3 treads per board, if stair treads included
       12” - Used for deck perimeter unless directed to use 7”
       12” - USed for stair outside facia - Assume 2x height length per side.

     Assume boards cover 5.25”.  So a deck that is 20’ wide and 10’ away from the house would require:
        10’ = 120” / 5.25” - 22.85  (23 grooved  boards @ 20’)
    For all deck boards we MUST try to minimize small pieces and user WHOLE boards.
        For a 10’ wide deck, we would use 20’ boards and cut them in half.
        For a 14’ wide deck, we would use 16’ deck boards (2’ waste)
        For a 22’ wide deck, we would use 12’ boards and double the count.
        For a 25’ wide deck… We use 16’ boards (2.5’ waste per board)

    For decks over 20’ we usually add a “divider board” - This is an additional S4S board with length > deck projection.
    For deck boards our primary concern is to ensure we use whole deck boards where possible and we may have waste.
